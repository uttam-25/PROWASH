# PROWASH PWA Icons

This directory must contain the following PNG icon files for PWA installation support:

- `icon-192.png` — 192×192 px PNG (required)
- `icon-512.png` — 512×512 px PNG (required)

These placeholder references are defined in `/public/manifest.json`.

**Before deploying to production**, replace these with real PROWASH-branded icons.
Icon generators such as [realfavicongenerator.net](https://realfavicongenerator.net) can produce
all required sizes from a single high-resolution source image.
