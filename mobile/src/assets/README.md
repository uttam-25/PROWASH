# Assets

Place the following image files in this directory before publishing the app:

- **icon.png** — App icon (1024×1024 px, PNG, no transparency for Android adaptive icon)
- **splash.png** — Splash screen image (1284×2778 px recommended, PNG)

Both images should use the PROWASH brand colors:
- Background: Midnight Navy `#0B1B2B`
- Accent: Ocean Blue `#147DAB` / Aqua `#40C4FF`

During development Expo will show a default placeholder if these files are missing.
